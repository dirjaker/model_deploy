## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/dirjaker/model_deploy.git
cd model_deploy

# 创建虚拟环境
conda create -n model_deploy python=3.12 -y
conda activate model_deploy

# 安装依赖
pip install -r requirements.txt

# 运行项目
python main.py
```
